# MVP Session Validation Checklist

Use this for 2 real sessions with your group.
Run it after P0 and P1 are done.

## Checklist (apply to Session 1 and Session 2)
- [ ] Login/sign-up works for all users.
- [ ] Welcome flow branches correctly to Player/Master.
- [ ] GM can host a campaign.
- [ ] Invite token flow works (invite + accept).
- [ ] Player can load and update their character sheet.
- [ ] Character changes persist after refresh/reopen.
- [ ] D10 rolls work (`roll >= difficulty`, success count shown).
- [ ] Session state controls work (idle/active/paused/ended).
- [ ] Public chat works for all campaign members.
- [ ] Private chat is visible only to sender + recipient.
- [ ] SSE realtime updates deliver new events/chat without manual refresh.
- [ ] Reconnect after temporary network drop recovers without breaking flow.
